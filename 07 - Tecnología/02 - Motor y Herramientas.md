# Motor y Herramientas

## Descripción de la sección

Documenta las herramientas utilizadas para crear el videojuego y por qué fueron seleccionadas.

## Motor

**Motor:** Unity

**Versión:** 6000.6.4f1 (Si se actualiza por tercera vez unity, modificar esto)

**Renderizado:** Universal Render Pipeline (URP)

**Física:** Unity 2D Physics

**Sistema de entrada:** Unity Input System

## Convenciones del proyecto

- **Estructura de carpetas:** Organización de archivos por categorías como escenas, scripts, prefabs, sprites, animaciones, audio y materiales.
- **Nomenclatura:** Uso de nombres descriptivos y consistentes para archivos, carpetas, objetos y scripts.
- **Control de versiones:** Uso de Git y GitHub para gestionar los cambios del proyecto mediante ramas.
- **Formato de assets:** Uso de formatos compatibles con Unity, principalmente PNG para recursos gráficos (sacados de itch.io) y formatos compatibles para audio.
- **Convenciones de código:** Uso de C# con nombres descriptivos, organización por responsabilidades y separación de funcionalidades en diferentes scripts.
