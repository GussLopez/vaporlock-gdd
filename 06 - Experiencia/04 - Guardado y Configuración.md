# Guardado y Configuración

## Descripción de la sección

Las partidas se guardan solo en el nivel que se quedo el jugador y guarda la cantidad de energía  y se puede eliminar la partida  si el jugador lo necesita realizar y al momento tambien el jugador le puede poner el nombre a su propia partida

## Guardado

**Tipo:**  Manual 

**Cuándo se guarda:** cuando el jugador entra al menú principal y ingresa al apartado de las partidas para salir del juego

**Qué datos se guardan:** Se guarda el nivel la cantidad de energía y la ubicación en el cual el jugador guardo las partidas

**Cantidad de ranuras:** Una sola ranura

**Qué ocurre si el guardado falla:** Se le da un aviso al juagdor para que vuelva a intentar volver a guardar la partida.

## Configuración

| Categoría     | Opciones                                                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Audio         | Se le da una opción de nivel de ajuste del sonido del 0 al 100                                                                     |
| Video         | Tenemos la opcion de Subir y bajar el brillo conforme la necesidad del jugador                                                     |
| Controles     | Muestra las teclas utilizadas para jugar y las acciones asociadas a cada una, como moverse, saltar, interactuar o pausar el juego. |
| Accesibilidad | Ofrece opciones para facilitar la experiencia de juego, como mostrar instrucciones claras, utilizar textos legibles                |
| Jugabilidad   | Permite configurar aspectos de la experiencia de juego                                                                             |

## Restablecimiento

¿Qué opciones pueden volver a valores predeterminados?
Las opciones son el apartado de Audio, y  video y los controles que son las opciones que se pueden volver a poner como estaban por defecto cuando el jugador ingresa al apartado de configuración y elige las opciones por defecto en el videojuego
