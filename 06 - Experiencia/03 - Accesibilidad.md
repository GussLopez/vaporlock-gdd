# Accesibilidad

## Descripción de la sección

La accesibilidad busca que el mayor número posible de jugadores pueda comprender y utilizar el videojuego.

- [ ] Tamaño de texto

- [ ] Sensibilidad
- [ ] Reducción de movimiento
- [ ] Reducción de destellos
- [x] Asistencia de apuntado
- [x] Dificultad ajustable
- [ ] Volumen independiente
- [ ] Indicadores visuales para sonidos importantes

## Consideraciones

**Controles:** Los controles deben ser intuitivos y fáciles de aprender para que el jugador pueda desplazarse e interactuar con los elementos del entorno.

**Interfaz*:* Los menús, mensajes e instrucciones deben ser claros para facilitar la comprensión de las mecánicas del juego.

**Rendimiento:** El videojuego debe funcionar de manera fluida y sin errores para evitar la molestia y mantener una buena experiencia en el jugador
